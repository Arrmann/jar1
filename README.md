# JARVIS Assistant 1.2.2 — AURA command integration

Настольный голосовой помощник для Windows 10/11 x64. Объединяет AURA AI (PySide6, SQLite, Whisper, Edge-TTS, OpenAI/Groq/Ollama) с каталогом команд JARVIS demo.

## Каталог команд

Импортировано 308 уникальных описаний и голосовых фраз из репозитория Arrmann/jar1:

- Основные — 13
- Управление — 169
- Ежедневные — 23
- Дополнительные — 30
- Заметки — 4
- Популярные — 69

Каталог: integration/command-catalog.json. Оригинальные Lua/PowerShell-команды и бинарные файлы демо напрямую не запускаются. Для подключённых функций написаны независимые обработчики Python в aura/actions/jarvis_commands.py.

На чистой установке без FFmpeg сейчас:
- 201 команда имеет обработчик и доступна сразу;
- 22 команды требуют дополнительных компонентов или настройки;
- 85 специальных сценариев пока отображаются в каталоге, но ещё не подключены.

Если FFmpeg установлен и доступен через PATH, команды записи экрана также переходят в статус «Работает».

## Реализовано

- Русское и английское распознавание речи через Faster-Whisper.
- Автоматическая попытка NVIDIA CUDA с переходом на CPU при ошибке CUDA/DLL.
- Голосовые ответы через Edge-TTS и резервный pyttsx3.
- OpenAI, Groq, Ollama и офлайн-режим.
- История диалогов и долговременная память SQLite.
- Диалоговый режим: после фразы «поговорим» можно говорить без повторного слова «Джарвис»; «закончи чат» возвращает режим ожидания.
- Диктовка в активное окно: «Джарвис, диктуй»; остановка — «останови диктовку».
- Управление мышью: левый/правый/двойной клик и перемещение курсора.
- Запуск приложений и сайтов, управление окнами и вкладками браузера.
- Системная громкость, яркость через поддерживаемый WMI, системные разделы Windows.
- Таймеры, напоминания, список задач.
- Снимки экрана; запись экрана при наличии FFmpeg.
- Озвучивание текста и чтение буфера обмена.
- Подтверждение рискованных системных операций.
- Библиотека команд с поиском, фильтрами по категориям и статусам.
- Тёмный HUD в стальном/циановом стиле.

## Что пока требует настройки или отдельной интеграции

LED-ленты и эффекты, Tuya/Smart Life, Obsidian, управление жестами, анализ экрана через vision-модель, генерация изображений и аватар-компаньон не выдаются за готовые функции. В библиотеке они отмечены как требующие настройки или находящиеся в плане. Для записи экрана нужен FFmpeg в PATH. Управление яркостью зависит от поддержки WMI конкретным монитором.

## Требования

- Windows 10/11 x64.
- Микрофон и динамики/наушники для голосового управления.
- Интернет для первоначальной загрузки модели Whisper, Edge-TTS и облачных AI API.
- Для ускорения Whisper на NVIDIA нужна совместимая CUDA-среда; при проблемах с ней выполняется CPU fallback.

Для запуска исходников нужен Python 3.13 или 3.14 x64.

## Установка из исходников

В PowerShell из корня проекта:

~~~powershell
.\install.ps1
.\run.ps1
~~~

Установка использует pygame-ce==2.5.8 и запрашивает готовый wheel, поэтому компилятор Visual Studio для pygame не требуется.

Для сборки EXE:

~~~powershell
.\build.ps1
~~~

Результат: dist\JARVIS.exe. Inno Setup конфигурация находится в installer/JARVIS.iss.

## Первая настройка

1. Открой раздел «Настройки».
2. Выбери OpenAI, Groq, Ollama или офлайн-режим.
3. Для OpenAI/Groq введи свой API-ключ. Он хранится в Windows Credential Manager.
4. Проверь голос, микрофон и горячую клавишу.
5. Для команд без AI-ответа (громкость, окна, запуск приложений, таймеры и т. п.) API-ключ не нужен.

Для голоса по умолчанию используется фраза активации «Джарвис» и непрерывный режим. Настройки можно изменить в приложении.

## Совместимость с прежней AURA

Путь пользовательских данных и имя службы Credential Manager сохранены: %APPDATA%\AURA_AI и AURA_AI. При обновлении на том же компьютере настройки, SQLite-база и API-ключи должны сохраниться. Не удаляй каталог AURA_AI при обновлении.

## Безопасность

- Закрытие приложений, удаление/перезапись файлов и рискованные системные действия требуют подтверждения.
- Выключение, перезагрузка, сон, закрытие активного окна, очистка корзины и очистка списка задач защищены подтверждением.
- Приложение не исполняет исходные Lua/PowerShell-команды из демо напрямую.
- API-ключи не записываются в config.json.

## Состояние сборки

Исходный проект находится в ветке chatgpt/aura-jarvis-integration; ветка main не изменялась. Перед установкой на основной компьютер рекомендуется проверить микрофон, API-провайдера и команды, зависящие от конкретного оборудования.
