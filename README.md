# AURA AI

AURA AI — персональный голосовой AI-помощник для Windows 11.

Возможности:

- Голосовой ввод через Faster-Whisper.
- Озвучка через Edge-TTS или pyttsx3.
- LLM-провайдеры: OpenAI, Groq, Ollama, резервный офлайн-режим.
- Память диалогов и долговременные заметки в SQLite.
- Управление приложениями, файлами, браузером и системной информацией.
- Подтверждение опасных действий.
- Журнал действий.
- Тёмный современный интерфейс на PySide6.

# Что реально реализовано в этом коде

## Голосовой контур

- Запись микрофона через `sounddevice`.
- Автоматическая остановка по тишине в непрерывном режиме.
- Глобальная горячая клавиша через `pynput`.
- Распознавание русской/английской речи через `faster-whisper`.
- Озвучка через `edge-tts` с естественными голосами.
- Резервная озвучка через `pyttsx3`, если Edge-TTS недоступен.
- Перебивание: при нажатии микрофона во время озвучки звук останавливается и начинается запись.

## Интеллект

- Поддержка OpenAI и OpenAI-compatible API, включая Groq.
- Поддержка Ollama.
- Офлайн-резерв, если ключи не заданы.
- Tool-calling: LLM сама решает, когда открыть приложение, искать файлы, читать сайты и т.д.
- Контекст последних сообщений сохраняется в SQLite.
- Долговременная память хранится отдельно и может пополняться инструментом `save_memory`.

## Безопасность

- Опасные инструменты помечены `dangerous`.
- Перед выполнением опасного действия появляется диалог подтверждения.
- Удаление защищено от части системных путей.
- Управление компьютером можно полностью отключить в настройках.
- Все действия пишутся в журнал `actions_log`.
- API-ключи хранятся через `keyring`, то есть в Windows Credential Manager, а не в `config.json`.

# Важные технические решения

## Почему выбран такой стек

- **PySide6** даёт нативный desktop UI и нормальную многопоточность через Qt-сигналы.
- **SQLite** не требует внешнего сервера и хорошо подходит для локальной памяти.
- **faster-whisper** быстрее и экономнее классического Whisper, особенно с `int8` на CPU.
- **Edge-TTS** даёт заметно более естественный голос без тяжёлых локальных TTS-моделей.
- **Ollama/OpenAI/Groq** закрывают сценарии: облако, локальная модель, быстрый облачный инференс.

## Как обрабатываются долгие операции

- LLM-запросы выполняются в фоновом потоке.
- Распознавание речи выполняется в фоновом потоке.
- Ожидание подтверждения пользователя блокирует только фоновый поток обработки запроса, не UI.
- Qt-сигналы доставляют результаты в главный поток интерфейса.
