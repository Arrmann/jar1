# JARVIS Assistant — AURA command integration

Настольный голосовой помощник для Windows 10/11 x64. Проект объединяет исходную архитектуру AURA AI (PySide6, SQLite, Whisper, Edge-TTS, OpenAI/Groq/Ollama) с импортированным каталогом команд демо JARVIS.

## Что вошло из демо JARVIS

Из репозитория `Arrmann/jar1` импортированы 308 уникальных описаний команд из категорий:

- Основные — 13
- Управление — 169
- Ежедневные — 23
- Дополнительные — 30
- Заметки — 4
- Популярные — 69

Каталог хранится в `integration/command-catalog.json`. Команды не исполняют оригинальные Lua/PowerShell-файлы напрямую: для поддерживаемых действий написаны независимые обработчики Python в `aura/actions/jarvis_commands.py`. В интерфейсе у каждой команды есть статус: «Работает», «Нужна настройка» или «В плане».

## Реализованные подсистемы

- Русский/английский голосовой ввод через Faster-Whisper.
- Попытка распознавания на NVIDIA CUDA с автоматическим fallback на CPU при ошибке загрузки или инференса.
- Голосовые ответы через Edge-TTS; pyttsx3 остаётся резервным движком.
- OpenAI, Groq, Ollama и офлайн-режим.
- История чатов и долговременная память в SQLite.
- Управление приложениями, сайтами, окнами и вкладками браузера.
- Системная громкость, поддерживаемая WMI яркость, системные страницы Windows.
- Таймеры, напоминания и список задач.
- Снимки экрана; запись экрана — при установленном FFmpeg.
- Подтверждение опасных действий.
- Отдельная страница каталога команд с поиском и фильтрами.
- Тёмный HUD в стальном/циановом стиле.

## Команды, требующие дополнительных компонентов

Некоторые элементы демо зависят от оборудования, личных данных или внешних сервисов. LED-ленты, Tuya/Smart Life, Obsidian, жесты, screen vision, генерация изображений и диктовка в другие окна не считаются готовыми без соответствующей интеграции. Они отмечены как требующие настройки или находятся в плане.

Запись экрана требует FFmpeg в PATH. Изменение яркости через WMI зависит от поддержки конкретного дисплея; на части настольных мониторов WMI недоступен.

## Системные требования

- Windows 10/11 x64.
- Python 3.13 или 3.14 x64 для запуска исходников.
- Микрофон и динамики/наушники для голосового режима.
- Интернет для Edge-TTS, загрузки модели Whisper и облачных AI API.
- Для ускорения Whisper на NVIDIA нужна совместимая CUDA-среда; при её отсутствии приложение переключится на CPU.

## Установка из исходников

Открой PowerShell в корне проекта и выполни:

```powershell
.install.ps1
.un.ps1
```

Установка использует `pygame-ce==2.5.8` вместо старого `pygame`: это предотвращает попытку pip собирать SDL/pygame из исходников на Python 3.14. Установщик принудительно запрашивает готовый wheel.

Сборка desktop EXE:

```powershell
.uild.ps1
```

После сборки приложение будет находиться в `dist\JARVIS.exe`.

## Первая настройка

1. Открой «Настройки».
2. Выбери OpenAI, Groq, Ollama или офлайн-режим.
3. Для OpenAI/Groq введи API-ключ; ключ хранится в Windows Credential Manager.
4. Проверь голос и микрофон.
5. По умолчанию новый профиль использует фразу активации «Джарвис» и непрерывный режим. Это можно отключить в настройках.

## Сохранение данных прежней AURA

Для совместимости с уже созданным профилем путь данных и имя службы Credential Manager оставлены прежними: `%APPDATA%\AURA_AI` и `AURA_AI`. Поэтому при обновлении на том же компьютере существующие настройки, база SQLite и API-ключи сохраняются. Не удаляй этот каталог при обновлении.

## Безопасность

- Закрытие приложений, удаление/перезапись файлов и системные команды требуют подтверждения.
- Выключение, перезагрузка, сон, закрытие активного окна, очистка корзины и очистка списка задач защищены отдельным подтверждением.
- Приложение не исполняет исходные Lua/PowerShell-команды из демо напрямую.
- API-ключи не записываются в `config.json`; используется Windows Credential Manager.

## Текущий статус разработки

Это интеграционная ветка разработки. Репозиторий `main` не изменён. Перед выпуском установщика необходимо провести Windows CI, smoke-тест на реальном Windows 11 и проверить голосовой сценарий на целевом ПК.
