JARVIS — голосовой помощник для Windows
=========================================

УСТАНОВКА (новый пользователь)
------------------------------
1. Запусти JARVIS-Setup-….exe
2. Прими лицензию
3. Оставь папку по умолчанию: C:\Program Files\JARVIS
   (так надёжнее всего на любом ПК; кириллица в пути тоже поддерживается)
4. Запусти ярлык JARVIS на рабочем столе
5. Разреши микрофон, если Windows спросит
6. Настройки → Лицензия → вставь ключ → Активировать

Если антивирус сообщил об угрозе: сохрани название обнаружения, версию JARVIS
и SHA-256 установщика. Обратись в поддержку для проверки; до выяснения причины
не отключай защиту и не восстанавливай файлы из карантина.

ОБНОВЛЕНИЕ / UPDATE (уже стоит старая версия)
------------------------------------
1. Полностью закрой JARVIS (иконка в трее / Диспетчер задач)
2. Запусти НОВЫЙ JARVIS-Setup-….exe
3. Оставь ту же папку установки (мастер сам подставит прошлый путь) → Установить
4. Готово: настройки, сценарии и лицензия в профиле Windows обычно сохраняются

Удалять старую версию перед обновлением НЕ нужно.
Удаляй через «Удаление программ», только если хочешь полностью снести программу
(там можно отдельно спросить про удаление настроек).

Нужно: Windows 10/11 x64, микрофон, интернет для активации ключа.

Если Windows пишет «Неизвестный издатель»: проверь источник файла и цифровую
подпись. При сомнениях обратись в поддержку до запуска.
