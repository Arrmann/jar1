ПЕРВЫЙ ЗАПУСК JARVIS (без ключа)
================================

1) Распакуй папку целиком. Не запускай программу из ZIP.
2) Запусти START_JARVIS.bat и подожди 5–10 секунд.
3) В окне нажми на сферу — так включается микрофон.
4) Говори в два шага:

   1. «Джарвис» — дождись короткого ответа
   2. команду целиком, например: «открой ютуб»

   Дальше — по одной фразе (каждый раз сначала «Джарвис»):
   - «разверни ютуб»   — полный экран ролика на YouTube
   - «громче» / «тише»
   - «как дела»
   - «сверни»          — свернуть текущее окно
   - «сверни все»
   - «открой блокнот»

Важно:
- Сначала «Джарвис», потом команда — не наоборот.
- «разверни» — развернуть окно Windows.
  «разверни ютуб» — полный экран видео на YouTube (это другая команда).
- Для фраз выше ключ не нужен. Остальное — после покупки;
  ключ вставляется в Настройках.

Если Windows пишет «Неизвестный издатель»:
  ПКМ по файлу → Свойства → «Разблокировать» → ОК
  или «Подробнее» → «Выполнить в любом случае».
