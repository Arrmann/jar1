# JARVIS — управление жестами (камера)

Движок: `jarvis_gestures.py` (MediaPipe HandLandmarker, одна рука, до 30 кадров/с).
Жесты распознаются по 3D-углам суставов, поэтому работают при любом наклоне кисти.

| Жест | Как | Что делает |
|------|-----|------------|
| **Указатель** | Указательный вверх (остальные согнуты) | Курсор (двигается по костяшкам — щипок его не сдвигает) |
| **Клик** | Короткий щипок большой + указательный | Левый клик там, где был курсор до щипка; два подряд — двойной клик |
| **Перетаскивание** | Щипок, удерживать ≥ 0.35 с | Зажать кнопку, тащить, разжать — отпустить |
| **Правый клик** | Короткий щипок большой + средний (указательный выпрямлен) | Правый клик |
| **Скролл** | «V» (указательный + средний), поднять/опустить руку от начальной точки | Прокрутка, скорость зависит от отклонения |
| **Окна** | Само, как только окно открылось, и ладонь ~0.3 с | Сразу, без плавного «доползания»: слева узкая колонка, справа большое окно, сверху по центру карточка. Ладонью карточку можно сдвинуть |
| **На весь экран** | Максимально раскрытая ладонь | Развернуть переднее окно |
| **Свернуть** | Кулак ~0.5 с | Свернуть активное окно (один раз за кулак) |
| **Команды** | Неподвижная «V» ~0.9 с, «три», «коза», «шака», «ILY», «четыре» ~0.5 с | Сценарии из Конструктора |

Выключить: удерживать Esc ~1 с или нажать Esc дважды; голос: «управление жестами» / «выключи жесты».

Диагностика: `%APPDATA%\com.jarvisn.assistant\gestures.log` и `gestures_status.json`
(поля `fps`, `infer_ms`, `camera_backend`). Окно предпросмотра: `JARVIS_GESTURES_PREVIEW=1`.
Тесты: `resources\tts\runtime\python\python.exe tools\test_gesture_classify.py`.
